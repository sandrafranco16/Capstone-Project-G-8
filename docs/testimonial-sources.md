## Adding or changing a testimonial

1. Record the exact quote, attribution and an accessible source (public URL, or
   a note of BITDOT's written approval with its date) in the table above.
2. Only then add it to `testimonials` in `src/features/home/leadership-content.ts`.
3. Mention the source in the pull request so reviewers can check it.

Before launch, BITDOT should confirm it is comfortable naming each person on the
site, including those quoted from public posts.
