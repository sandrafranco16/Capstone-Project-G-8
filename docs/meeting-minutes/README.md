# Meeting Minutes

This folder contains meeting records for the BITDOT Marketing and Training Platform capstone project.

Meeting minutes and related records are maintained for:

- Client meetings
- Facilitator meetings
- Sprint reviews
- Internal team meetings

These records support project communication, decision tracking and client approval evidence.
